# 🤖 JARVIS Voice Assistant (Python)

This is a **basic JARVIS-style AI voice assistant** built using Python.
It listens to voice commands and responds with voice replies.

## 🚀 Features

* 🎤 Voice command recognition
* 🗣️ Text-to-Speech voice replies
* 🌐 Open websites like YouTube and Google
* ⏰ Tell the current time
* 🖥️ Simple JARVIS-style UI using OpenCV

## 🛠️ Technologies Used

* Python
* SpeechRecognition
* pyttsx3
* OpenCV
* NumPy

## 📦 Installation

Install the required packages:

```bash
pip install SpeechRecognition
pip install pyttsx3
pip install opencv-python
pip install numpy
pip install pyaudio
```

## ▶️ Run the Project

```bash
python jarvis.py
```
